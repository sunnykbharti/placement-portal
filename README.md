# placement-portal
Travail is my college project that i was assigned for my MAD-1(Modern Application Development 1) project. As part of my project, I have (Since I'm working) to create a Placement portal.

Tech Stack: This Project is made using HTML, CSS - for frontend, Flask - for Backend, SQLite - for Database and SQLAlchemy - for ORM.

About: The Placement portal has Admin as Super user, which can monitor and manage Students, Companies, Drives and applications. Companies can register but require admin approval to access dashboard, once approved they can create drives and manage them. Students can register and apply for Drives whichever and whenever they find a fit for.
